# Yomu - Markdown Reader with Japanese Typography

[![CI](https://github.com/shou6/yomu/actions/workflows/ci.yml/badge.svg)](https://github.com/shou6/yomu/actions/workflows/ci.yml)

[English](README.md)

Yomu は Markdown を専用のリーダータブで開き、日本語を読むための組版で表示する拡張機能です。
編集はしません。直したくなったら標準のテキストエディタで開きます。

## 機能

- **リーダータブ**：`.md` をカスタムエディタのタブで開く。既定のエディタは奪わず、コマンドパレットか「エディターを再度開く方法を選択」から明示的に開く
- **日本語組版**：行長の固定（全角 38 字程度）、和文と欧文のフォントの出し分け、日本語向けの行間、約物のアキ詰め。Web フォントは同梱せず、システムフォントを使う
- **レンダリング**：CommonMark と GFM の表・取り消し線・タスクリスト、コードブロックのシンタックスハイライト、見出しのアンカー、ローカルとリモートの画像。生の HTML は無効
- **テーマへの追従**：ライト、ダーク、ハイコントラストに対応し、タブを開き直さなくても切り替わる
- **編集への追従**：テキストエディタで編集して保存すると、リーダータブの内容が更新される

## 使い方

1. `.md` ファイルを開く
2. コマンドパレット（`Ctrl+Shift+P` / `Cmd+Shift+P`）を開き、**Yomu: リーダーで開く** を実行する。「エディターを再度開く方法を選択」から **Yomu Reader** を選んでも開ける
3. 編集する時は「エディターを再度開く方法を選択」から **テキスト エディター** を選ぶ

## 動作環境

- Visual Studio Code 1.138 以上
