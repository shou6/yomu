## 機能

- **Hello World**：開いているフォルダの名前を入れて挨拶を表示する

## 使い方

1. コマンドパレット（`Ctrl+Shift+P` / `Cmd+Shift+P`）を開く
2. **Yomu - Markdown Reader with Japanese Typography: Hello World** を実行する

## 動作環境

- Visual Studio Code 1.138 以上
